---
title: 查源码、图谱与代码问答
description: 选择符号检索、语义搜索或项目 Wiki，核对答案来源及模型配置。
---

从「代码」进入一个索引已就绪的仓库。开始前确认当前仓库和版本；需要与其他人协作时通过资源权限授予仓库访问。

| 要完成的任务 | 入口与核对方法 |
| --- | --- |
| 找已知的类、函数或路径 | 使用搜索中的精确线索，打开源码核对定义和相关调用 |
| 理解调用关系或影响范围 | 在图谱选择代表节点，展开邻居或查看影响范围，再回源码确认条件和调用点 |
| 提自然语言问题 | 使用语义搜索或智能问答。提示中带上文件、模块、异常现象，对照引用行复核 |
| 先了解项目结构 | 查看概览或项目 Wiki。摘要帮助定位模块，结论仍回到实际文件确认 |

例如对演示仓提问「哪个函数返回发布标识？」。先按符号查它的定义，再问自然语言问题。检查回答链接是否指向当前仓库正确文件和行号。对涉及调用顺序的回答，再打开图谱或直接查看调用代码。

文件 AI 摘要、概览的项目摘要及搜索问答可能使用各自的模型配置。语义结果为空先检查向量索引、模型和团队授权；词条能找到而语义结果不理想时，用相同仓库版本和同一个问题分别测试精确检索和语义检索。

在智能体或工作流里使用代码仓工具时，用实际业务账号验证仓库及模型权限。需要更新来源时先按[更新仓库版本与索引](./update.mdx)完成同步。
