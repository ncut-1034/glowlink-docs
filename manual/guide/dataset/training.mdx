---
title: 查看处理状态与索引
description: 区分预览、解析、分块和嵌入，定位排队、异常及重建问题。
---

在「知识库 → 数据集」查看集合列表。进入文件或集合可检查切片、原文和索引。准备发布前，保持要验收的资料版本、模型及检索问题固定。

| 看到的状态或阶段 | 下一步 |
| --- | --- |
| 排队、等待前置阶段 | 检查该文件是否尚在解析，或团队的后台额度是否已占满 |
| 解析和分块处理中 | 等待正文和切片就绪；完成后抽查标题、数字、表格和引用位置 |
| 嵌入或重建中 | 核对索引模型和处理进度。提交检索验收前等待对应索引可用 |
| 训练异常 | 打开异常列表，按阶段确认是文件解析、模型授权、连接还是额度。修正后按界面重试 |
| 已有切片 | 打开切片并用一条明确问题做检索测试，确认从检索结果能回到正确来源 |

### 更新资料时

- 原文变更后看该集合是否需要同步或重新处理。修改切片或重建后，用固定问题复验。
- 判断模型是否可用时同时核对平台启用、团队配置、实际执行者授权与额度。权限不足时，找管理员处理当前团队的模型配置。
- 使用 [Wiki 与知识网络](./wiki.mdx) 的团队，在普通索引可用后按需发起 Wiki 提取。训练完成、Wiki 缓存和可核对的原文证据分别检查。

### 验收例子

从示例制度中选择一条固定问题，记录资料名、预期答案、检索命中文本及页内来源。修正参数后重复同一问法。看得到切片但命中不理想时进入[检索测试](./search-test.mdx)比较，而不是连续重传同一文件。
