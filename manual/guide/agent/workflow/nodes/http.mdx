## 设置调用

选择请求方法，在地址填写目标环境授权且部署服务器可访问的接口。按接口契约填写查询参数、请求头和请求体。敏感值优先使用页面提供的凭据设置。填写超时时间后，将上游变量按参数类型接入。

## 查看响应与错误

可以引用原始响应，或按界面从响应中提取所需字段供后续节点使用。失败时查看完整错误和执行详情，区分不可达、超时、HTTP 状态及业务错误。可恢复异常用条件分支给出明确的用户反馈。

## 示例

在合成环境通过只读接口查申请状态。把提取节点返回的申请编号接入查询参数，将响应的状态字段接到指定回复。用存在及不存在的编号测试，核对请求参数和下游拿到的值，再验证接口不可用时的提示。
