## 输入和输出如何匹配

确认交付环境启用对应沙箱。选择编辑器内支持的语言，在节点声明输入变量并连接上游值。代码入口接收同名参数，返回字段与节点中配置的输出名称及类型对齐。

## JavaScript 示例

添加数值型输入 `data1`、`data2` 和数值型输出 `result`：

```js
async function main({ data1, data2 }) {
  return { result: data1 + data2 }
}
```

用 2 和 3 调试，确认输出为数字 5，再接入下游。传入字符串或空值时分别测试，避免拼接成字符串或产生意外结果。

## 排查

代码报错时先核对入口函数、输入名称、返回值类型及执行日志。依赖、文件和网络能力取决于交付侧配置，代码中引用前先确认实际环境已准备。
