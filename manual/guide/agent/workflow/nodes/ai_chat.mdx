## 输入怎么接

| 输入 | 常见配置 |
| --- | --- |
| AI 模型 | 选当前团队可用的语言模型。模型参数决定上下文、输出长度等限制 |
| 用户问题 | 引用开始节点的输入，也可以引用上游改写后的问题 |
| 提示词 | 说明回答任务、输出格式以及允许使用的资料范围 |
| 聊天记录 | 按需保留历史轮次，或引用上游产出的聊天记录 |
| 知识库引用 | 接入知识库搜索或引用合并节点输出 |
| 文件链接 | 按模型能力和节点配置接入；需提取正文时先走读取文件 |

## 输出和连线

下游可以引用 AI 回复文本，也可按类型引用新上下文。隐藏 AI 输出时，结果仍可供下游处理，适合「先生成，再校验或重排」。模型故障与没有检索依据是两种情况，分别检查节点错误和上游引用。

## 示例

把差旅制度的检索结果接入引用输入，提示词要求按原文给出期限。调试时核对上游引用确实含有期限，再检查答案。如果要用「指定回复」统一格式，打开隐藏输出，避免一轮出现两条回答。
