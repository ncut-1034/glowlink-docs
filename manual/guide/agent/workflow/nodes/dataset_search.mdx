## 选择知识库和检索内容

在节点里选可访问且处理完成的知识库。需要搜索多个库时按界面核对向量模型是否兼容。把开始节点的问题或上游优化后的问法接到检索输入；引用数组类型输入时检查每项是否为字符串，避免把整份对话记录作为问题。

## 搜索参数

| 配置 | 检查方式 |
| --- | --- |
| 搜索模式 | 先对比关键词和语义检索，再按资料类型选择混合等模式 |
| 相关度与引用上限 | 阈值过高可能没有结果；引用上限影响传给下游的内容长度 |
| 重排与关键词展开 | 启用前确认对应模型授权和服务可用，并用同一组题比较效果 |
| 资料范围 | 检查选择的库和可用的过滤条件，避免无关语料进入上下文 |

## 示例与空结果

按「开始 → 知识库搜索 → AI 对话」连线。AI 对话的用户问题引用开始节点，知识库引用选搜索节点的输出。问「出差结束后多久提交报销？」，先在调试里核对返回内容里的 15 个自然日，再核对生成答案。检索没有匹配内容时，引用数组可以为空；用缺少依据的提问验证下游回复。若节点执行失败，先查看模型、权限、额度和错误详情。
