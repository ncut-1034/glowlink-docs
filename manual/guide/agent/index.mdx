---
title: 智能体
description: 创建和调试智能体，按需编排并发布工作流。
---

1. 进入「智能体」，选择新建方式。需要串联检索、判断、模型和外部服务时，选择工作流。
2. 在配置或编排界面填写模型、提示词和所需知识库。连线后检查下游输入引用的是上游节点的输出。
3. 用正常问题、查不到资料的问题分别调试。查看节点输出，检查引用及错误提示，再保存和发布。
4. 发布后用目标使用者的权限检查入口和可见范围。应用编辑权限和应用使用权限应分别确认。

工作流节点右上角的书本图标可找到具体参数说明。常用节点包括 [AI 对话](./workflow/nodes/ai_chat.mdx)、[知识库搜索](./workflow/nodes/dataset_search.mdx)和[条件判断](./workflow/nodes/tfswitch.mdx)。
